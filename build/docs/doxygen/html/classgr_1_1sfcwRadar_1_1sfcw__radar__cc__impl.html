Class Constructor. The jobs include:

  1. Initialise sample buffers
    See also
    init_sample_buffers()
  2. Create an instance of BladerfDevice, and set it to use two TX and two RXs, one pair for radar channel, one pair for reference channel
  3. Provide frequency plan to the device to enable quick tune functionality
    Parameters
    start_freqThe start frequency of the frequency plan in Hz
    num_stepsNumber of frequency steps
    step_sizeThe gap between two consecutive frequencies in Hz
    samp_rateSampling rate in Hz
    rx_gainThe gain of the radar RX channel
    tx_gainThe gain of the radar TX channel
    ref_gainThe gain of the reference TX and RX channel
    enable_biasteeSet the flag if BT-100 and BT-200 are connected with radar TX and radar RX channels
    burst_lenNumber of samples per pulse
    recv_buf_lenNumber of samples to receive from one RX channel. Prefer to be bigger than burst_len
    num_buffersNumber of buffers to use in the underlying data stream
    buffer_sizeThe size of the underlying steam buffers, in samples. Must be a multiple of 1024. Samples are only transferred when a buffer of this size is filled.
    num_transfersThe number of active USB transfers that may be in-flight at any given time
    pulse_amplitudeThe amplitude of the transmitted pulse
    cw_frequencyThe baseband frequency of the single tone pulse
    isChirpSet this when using chirp waveform
    chirp_bandwidthBandiwdth of chirp
    ts_inc_sendAfter each frequency tunning, wait ts_inc_send ms before transmitting radar pulse and receiving radar echo.
    Note
    that ts_inc_send depends on the processing power and the USB overhead of the host computer. It is recommand to be larger than 1.

int gr::sfcwRadar::sfcw_radar_cc_impl::work ( int  noutput_items,
gr_vector_const_void_star &  input_items,
gr_vector_void_star &  output_items 
)

Sweep the frequency, send pulse and receive echos for each frequency step Jobs include:

  1. add newScan tag at the begining of the SFCW pulse, and step tag at the begining of each subpulse
  2. tune LO of tx and rx channels to sweep the frequency
  3. generate subpulse samples, either single tone or chirp, and store them into _32fcbuf_in and then _16icbuf_in
  4. control bladeRF device to send subpulse and receive echos
  5. output received samples
    Returns
    d_num_steps*d_recv_len number of samples per output port
